# Blankoleo

Übersichtsseite für meine kleinen Apps – https://blankoleo.github.io/

Reines HTML/CSS (plus ein kleines `app.js` für den Teilen-Knopf), keine externen Dateien, keine Tracker.

## Projekt ergänzen

1. Icon nach `assets/` legen (quadratisch, SVG oder PNG ab 192 px).
2. In `index.html` einen `<li class="project">`-Block kopieren und Link, Icon, Name, Satz sowie die zwei Nebelfarben `--c1`/`--c2` anpassen.
3. Optional: `assets/og.png` (1200×630, Vorschau beim Teilen) neu erzeugen.

## Lokal ansehen

    python3 -m http.server 8780
